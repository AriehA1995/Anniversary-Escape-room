# Online Escape Room Game
An interactive digital escape room where users solve puzzles to find a password.
## Technologies Used
- PHP (backend)
- JSON (data storage)
- JavaScript, HTML, CSS (frontend)
## Features
- Clue-based puzzle system
- Server-side data management
- Responsive frontend design
## Installation
1. Install PHP server
2. Put the project into htdocs file
3. Run the server
4. Go to localhost/Anniversary-Escape-room
